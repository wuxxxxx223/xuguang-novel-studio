# 作品主界面与从零抽卡流程

## 功能名

作品主界面 → 新建作品 → Idea 抽卡 → 具体作品工作台。

## 用户任务

用户打开叙光时先看到自己的作品，而不是被直接塞进某一本小说。没有 Idea 时，可以创建一个独立作品，选择完全随机或填写大概方向，然后进入 Idea 阶段抽卡。

## 进入条件

- 服务端已启动，作品库接口可读。
- 历史 `.data/workspace.json` 若存在，首次读取时无损迁移为一个独立作品。
- 模型未配置不阻止创建作品，只阻止实际调用 AI 抽卡。

## 退出条件

- 用户已打开一个已有作品；或
- 用户已创建一个新的独立作品，并进入 Idea 抽卡页；或
- 用户显式选择了磁盘中的正式正文项目，进入该项目今日工作台。

## 主流程

1. 应用启动后进入作品主界面。
2. 主界面展示最近的创作 Workspace，以及扫描到的正式正文项目。
3. 用户点击唯一主动作“新建作品”。
4. 新建页允许填写可选作品名、类型，并选择“完全随机”或“给定方向”。
5. 用户点击“创建作品并进入抽卡”。
6. 服务端新建独立 Workspace、设为当前作品并保留其他作品。
7. 页面进入该作品的 Idea 阶段，展示抽卡面板。
8. 用户点击“抽一组 Idea”；结果先进入建议稿，确认后才成为事实。
9. 在任一具体作品页面，用户都可以点击左上角返回作品主界面。

## 分支流程

| 情况 | 去哪里 | 用户看到什么 | 写入什么账本 |
|---|---|---|---|
| 打开最近作品 | 该作品今日工作台 | 当前阶段、风险、下一步 | 只更新当前作品指针 |
| 新建完全随机作品 | Idea 抽卡页 | 不带方向限制的抽卡入口 | `.data/workspaces/<id>.json` |
| 新建定向作品 | Idea 抽卡页 | 已填入方向限制的抽卡入口 | `.data/workspaces/<id>.json` |
| 模型未配置 | Idea 抽卡页 + 配置抽屉 | 缺少 Idea 模型路由 | `.data/settings.json` |
| 打开正式正文项目 | 项目今日工作台 | 当前章、章节契约、风险 | 不改正式项目；侧车仍写 `.data/` |
| 历史单 Workspace | 作品主界面 | 历史作品作为最近作品出现 | 首次迁移到 `.data/workspaces/` |
| 返回主界面 | 作品主界面 | 所有作品入口 | 不修改作品正文或阶段状态 |

## 状态

- 未开始：作品主界面没有创作 Workspace。
- 进行中：新建表单正在填写，或作品正在打开。
- 待确认：抽卡结果已生成，等待作者确认。
- 已完成：新作品已创建并进入 Idea 工作台。
- 阻塞：作品库服务不可用，或实际抽卡缺少模型配置。

## 风险

| 优先级 | 风险 | 如何展示 | 如何处理 |
|---|---|---|---|
| P0 | 新建作品覆盖现有 Workspace | 新建前不复用当前文件 | 每个 Workspace 独立文件，旧文件首次无损迁移 |
| P0 | 切换作品后保存到错误作品 | 顶栏始终显示当前作品 | 服务端维护唯一当前 Workspace ID，保存带 revision 校验 |
| P1 | 正式正文项目和创作 Workspace 混为一类 | 主界面分成两个区块 | “创作中的作品”与“已有正文项目”分层展示 |
| P1 | 新建即自动花费模型额度 | 新建按钮文案明确“进入抽卡” | 创建只落账本；实际调用由抽卡页单独确认 |
| P1 | 主界面动作过多 | 新建作品为唯一强调按钮 | 打开已有作品使用卡片次动作 |

## 主动作

作品主界面唯一主动作：**新建作品**。

新建作品页唯一主动作：**创建作品并进入抽卡**。

## 次动作

- 打开最近作品。
- 打开已有正文项目。
- 取消新建，返回作品列表。
- 打开模型配置。

## 完成后写入

- `.data/workspaces/<workspace-id>.json`：每个创作 Workspace 的独立状态。
- `.data/workspace-active.json`：当前创作 Workspace ID。
- `.data/workspace.json`：当前 Workspace 的兼容镜像，供现有调用链继续使用。
