# 作品主界面页面规格

## 页面名

作品主界面 / 新建作品 / 具体作品工作台。

## 页面目的

先回答“我要处理哪一本书”，再回答“这本书下一步做什么”。用户不应在应用启动时被默认带入某一本具体小说。

## 顶部状态

### 作品主界面

- 产品：叙光 Novel Studio。
- 位置：作品主界面。
- 全局状态：创作 Workspace 数、正式正文项目数。
- 设置：模型配置入口。

### 具体作品工作台

- 返回主界面按钮。
- 当前作品、当前对象、当前阶段、保存状态和风险。

## 左侧导航

作品主界面不展示五阶段导航，避免在尚未选书时伪造当前位置。

进入具体创作 Workspace 后恢复：

- 今日
- Idea
- 故事引擎
- 小说蓝图
- 章节写作
- 审查定稿

进入正式正文项目后恢复章节日更导航。

## 中间主内容

### 作品主界面

1. 页面标题与一句说明。
2. 唯一主动作“新建作品”。
3. “创作中的作品”卡片列表：作品名、类型、当前阶段、完成阶段数、更新时间。
4. “已有正文项目”卡片列表：作品名、当前章、当前状态、更新时间。
5. 空状态只解释下一步，不展示文件树、工具列表或营销 Hero。

### 新建作品

1. 可选作品名。
2. 可选类型。
3. 抽卡方式：完全随机 / 给定方向。
4. 给定方向时显示约束输入框。
5. 唯一主动作“创建作品并进入抽卡”。

### Idea 抽卡页

复用现有 Idea 抽卡面板，方向选择和约束从新建页带入；实际模型调用仍由用户单独点击。

## 右侧检查器

作品主界面不展示作品检查器。进入具体作品后才展示对应检查器。

## 底部命令

作品主界面不显示阶段主动作 Dock。新建作品页的主动作放在表单底部。

## 主动作

- 作品主界面：新建作品。
- 新建作品页：创建作品并进入抽卡。
- Idea 抽卡页：抽一组 Idea。

## 空状态

- 没有创作 Workspace：说明“从完全随机或给定方向开始”，主动作仍是新建作品。
- 没有正式正文项目：显示中性说明，不把它当错误。

## 阻塞状态

- 作品库读取失败：显示连接错误和重试，不静默回退到覆盖式单 Workspace。
- 创建失败：保留表单内容，显示服务端错误。
- Idea 模型未配置：作品已创建且内容不丢失，打开模型配置抽屉后恢复。

## 完成状态

新建成功后进入该作品 Idea 页，顶栏显示新作品名或“未命名作品”，抽卡模式和方向已填入。

## 不展示

- `.data` 文件路径和内部 ID。
- 正式项目绝对路径。
- API Key 原文。
- 原始文件树。
- 未选作品时的阶段检查器和阶段主动作。
